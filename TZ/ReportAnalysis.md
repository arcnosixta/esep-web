## 5. Отличия по типу объекта

- **Квартира/дом/ЗУ**: полный скелет, акт осмотра, 3–4 приложения.
- **Нежилое (подвал)**: тот же скелет; назначение — налогообложение;
  в разделе 3 нет 3.3 (расчёт по сравнительному) — сразу согласование.
- **ЗУ + строение раздельно (налог)**: раздел 3 расширен:
  3.4 расчёт ЗУ + 3.5 расчёт строения отдельно + 3.6 согласование;
  приложения: фото, аналоги (без акта осмотра).
- **Авто**: сокращённый формат (22 стр.): без акта осмотра и фото в
  приложениях, другая нормативка, раздел 2 описывает ТС (марка, модель,
  VIN, пробег, год, состояние).

## 6. GAP: наш отчёт (4–5 стр.) vs шаблон (40–58 стр.)

Наше приложение генерит 4 раздела (1–4) одним «ИИ-текстом». Не хватает:

1. **Константные разделы** (дают ~10–15 стр.): 1.4 допущения, 1.5 нормативка,
   1.6 термины, 3.1 методология — сейчас их нет вообще.
2. **Титул по шаблону** — таблица паспортных полей + стоимость прописью.
3. **Табличные данные Раздела 2** — характеристики здания и объекта
   (сейчас ИИ пишет прозой; в шаблоне — таблицы).
4. **Таблица аналогов с корректировками** (3.3) — адрес, площадь, цена,
   поправки % → скорректированная цена.
5. **Приложения**: акт осмотра, фотографии (из заявки), аналоги, документы.
6. **Содержание с номерами страниц.**
7. Номер отчёта в формате G-XXXX, сумма прописью.

## 7. Предложение: новая архитектура генерации

**Три источника данных:**

| Источник | Что даёт | Кто готовит |
|---|---|---|
| Константы (шаблон в коде) | титул-шапка, юрлицо, оценщик, 1.4, 1.5, 1.6, 3.1, футер | один раз при разработке |
| Данные заявки (БД) | заказчик, объект, адрес, даты, фото, документы | клиент + оценщик (редактор отчёта) |
| ИИ (Gemini) | раздел 2 (описание объекта), аналоги с корректировками (3.2–3.3), согласование (3.4), заключение (4) | генерация + правки оценщика |

**Порядок сборки PDF** (новая версия `report_service.dart`):
1. Титул (константа + переменные + сумма прописью)
2. Содержание (авто-номера страниц)
3. Раздел 1: 1.1–1.3 из заявки, 1.4–1.6 константы
4. Раздел 2: таблицы из данных заявки + текст ИИ
5. Раздел 3: методология (константа) + таблица аналогов (ИИ/оценщик) + согласование
6. Раздел 4: заключение (ИИ + подпись оценщика)
7. Приложения: акт осмотра, фото (из storage), аналоги, документы

   недвижимость?

   варианту 15–20 стр. (константы + таблицы + 2 приложения)?
