1. ТӨЛЕМ НЕ ҮШІН КЕРЕК?
----------------------------------------------------------------
ESEP — GaMa Group ТОО-ның мүлік бағалау қызметі (Flutter +
Supabase + Cloudflare Pages). Пайдаланушы AI-chat арқылы
өтініш жасайды, ресми бағалау отчетын алады.
РЕСМИ ОТЧЕТ АҚЫЛЫ — 15 000 ₸.

Төлем экранының пайда болу орындары:
  - ai_chat_screen.dart:628 — AI өтініш жасағаннан кейін автоматты ашылады
  - case_detail_screen.dart:337 — «Оплатить» батырмасы (pending_payment)
  - home_screen.dart:278 — Басты беттегі «Оплата» quick-action

Төлегеннен кейін: payments=paid, applications=paid, reports=paid
→ «Скачать официальный отчёт» батырмасы ашылады.

Бұрынғы 3 әдіс: банк аударым (менеджер растайды),
Kaspi Pay (қолмен), Kaspi online (демо).
XPAYMENT = 4-ші әдіс: онлайн АВТОПОДТВЕРЖДЕНИЕ,
менеджерді күтпейді.

2. НЕ ЖАСАЛДЫ (6 ФАЙЛ)
----------------------------------------------------------------
[ЖАҢА]
a) functions/api/xpayment.js — Cloudflare Pages Function:
   * POST /api/xpayment/create  — JWT тексереді, payments
     жазбасын жасайды (method=xpayment), XPayment-тен
     платёжная ссылка сұрайды, checkout_url қайтарады
   * POST /api/xpayment/status  — polling: XPaymentтен статус
     сұрап, COMPLETED болса өздігінен растайды
   * POST /api/xpayment/webhook — eventтерді қабылдайды,
     X-xPayment-Signature (HMAC-SHA256) тексереді,
     идемпотенттік (қайталанған delivery_id өткеріледі)
   * GET /api/xpayment/checkout — демо бет (кілтсіз режим)

b) lib/services/xpayment_service.dart — Flutter сервисі:
   * createCheckout() — серверге сұраныс жіберіп URL алады
   * syncStatus() — статуспен синхронизация

c) lib/screens/xpayment_screen.dart — төлем экраны:
   * Сілтеме ашылады → Kaspi қосымшасы → клиент төлейді
   * Әр 5 секунд сайын статус тексеріледі (макс 60 рет)
   * Төленсе конфетти + «Оплата прошла успешно»

d) supabase_xpayment.sql — БД миграциясы:
   * CHECK шектеулерді кеңейтеді:
     method   += xpayment, bank, kaspi_online

3. ЖҰМЫС ІСТЕУ ШЕМБЕРІ
----------------------------------------------------------------
Flutter экраны
  → POST /api/xpayment/create (Supabase JWT арқылы)
  → Cloudflare: payments жазбасы (pending) жасайды
  → XPayment API: POST /v1/payments/link (сілтеме сұрайды)
  → Flutter checkout_url ашады → Kaspi қосымшасы
  → Клиент «Оплатить» басады (15 000 ₸)
  → XPayment webhook жібереді (payment.completed + қолтаңба)
  → Сервер HMAC тексереді → payments=paid, applications=paid,
    reports=paid
  → Flutter экраны 5 сек сайын тексеріп, конфетти көрсетеді

API ақпараты: https://xpayment.kz/docs
  - Авторизация: Authorization: Bearer xdev_...
  - Платёжная ссылка ~5 минут жұмыс істейді
  - Webhook қолтаңбасы: hex(HMAC-SHA256(secret, raw_body))
    заголовокта X-xPayment-Signature түрінде келеді
